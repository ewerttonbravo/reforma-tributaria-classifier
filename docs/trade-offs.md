# Trade-offs

Compromises made consciously and why. This document grows with each task.

Each compromise has a kind: a **design choice** would stay the same with more time; a **temporary** one has a planned removal.

| Area | Kind | Compromise | Why | Way out |
|---|---|---|---|---|
| Module boundaries | Design choice | Layering enforced by tests, not by the compiler | A single module keeps the build simple | Split into Maven modules if the codebase grows |
| Build time | Design choice | PIT runs in every `verify`, locally and in CI | A mutation gate that runs only on demand stops being run | Incremental analysis (`withHistory`) if the build gets slow |
| AI prompt size | Design choice | The AI receives all 164 `cClassTrib`, not only those linked to the product's NCM | The calculator offers no list by NCM (D5); checking each candidate would take 164 calls per product | Pre-filter with `ncm-aplicavel` or the calculator's annex tables if cost or accuracy demand it |
| Calculator build | Temporary | The calculator is built with `-Dmaven.compiler.proc=full`, a flag its README does not mention | Release `1.6.1` targets Java 21 and does not build on JDK 25 without it (D4) | Drop the flag when a pinned release builds on JDK 25 as published |
| CSV format | Design choice | Fields are split on `;` with no quoting, so a description cannot contain `;` | The catalog is fictitious and one split keeps the parser small; a line with an extra `;` is rejected, never misread | An RFC 4180 parser in the adapter if real catalogs need it |
| Durability | Design choice | The local broker and the test broker keep one replica, so `acks=all` waits for the leader only | One machine runs the demo; three brokers would add nothing the tests can observe | Three brokers, replication factor 3 and `min.insync.replicas=2` in production |
| CSV encoding | Design choice | Only UTF-8 is read; a file saved as Windows-1252, the default of Excel in Brazil, fails with exit code 2 | Guessing the encoding could turn `Feijão` into `FeijÃ£o` without anyone noticing, and the description is what the AI classifies | An `--encoding` option if real catalogs need it |
| Logging | Temporary | Logs below WARN are dropped and Spring Kafka logs nothing, so the publish command's stdout is its summary alone | The application is only a command for now, and the command prints its own failure | Task 07b sets the levels the long-running consumer needs |
| Calculator timeout | Temporary | No timeout is set on the call to the calculator, so a calculator that hangs can hold the caller | Timeouts and retries of the calculator are one behavior, tested together against a stub server | Task 12 sets connect and read timeouts and retries a timeout with backoff |
| Calculator failure type | Temporary | The candidates and legal basis ports fail with Spring's `RestClientResponseException`, or a `NullPointerException` for a missing body, `cClassTrib` array or code, which the application layer cannot name | Nothing calls these ports yet; the AI port got its failure type in task 06b (D12), and the calculator's is decided with its retries | Task 12 declares the ports' failure and the adapters translate into it |
| AI confidence | Design choice | The confidence threshold trusts the confidence the AI declares, which is not calibrated: a wrong suggestion can come with high confidence | The official list catches unofficial codes and the calculator catches a `cClassTrib` not linked to the NCM (D5); the threshold only filters the answers the AI itself doubts | Calibrate the threshold against the accountant's review decisions once there are enough of them |
| AI client footprint | Design choice | The Anthropic SDK brings OkHttp, Jackson 2, Kotlin and OpenTelemetry next to Spring's Jackson 3 | The official SDK gives typed requests, structured output from a record and typed errors; writing the Messages API by hand would repeat that | Call the Messages API with `RestClient` if the footprint ever costs more than it saves |
| AI failure type | Temporary | A Claude call that gets no answer, for a refused connection or a timeout, surfaces as the SDK's `AnthropicIoException`, not as `AiFailure` | Timeouts and retries of the AI are one behavior, tested together against a stub server | Task 12 sets the timeouts and turns an I/O failure into `AiFailure` |
| Missing legal basis | Design choice | An accepted suggestion of a `cClassTrib` with no published legal basis (220001, 220002, 220003) reaches the accountant without a legal citation | The calculator publishes none for them (D13); sending them to review would flag a choice the AI did not get wrong | Send them to review if accountants ask for a citation on every classification |
